# Embedding
An embedding is a ***learned numerical representation*** of an item that captures ***useful relationships with other items***.

king:     [0.81, 0.32, -0.52, 0.17]
queen:    [0.82, 0.33, -0.51, 0.18]
banana:   [0.69, 0.21,  0.88, 0.93]

Model is not given these values by a human
During training, the embedding values are learned.
The system obeserves how tokens are used across enormous amounts of text.
Words appearing in similar linguistic environments gradually develop useful numerical relationships.

An embedding iss not the meaning of a word. It is a numerical representation that captures  useful patterns about that words.


Embedding as co-ordinates

# Cosine Similarity
It compares the angle between 2 vectors. It focuses more on direction than on absolute length.

If 2 vectors point in a similar direction, the represented concepts may be similar.
If they point in unrelated directions, the concepts may be less similar.

e.g.
- reset password
- I no longer remember my password and need to create a new one
have different lengths, but their semantic direction can still be similar.

Vector A and B point is the same direction.
Even though B is longer, their cosine similarity is very high.
Vector C points in a different direction.
So it has lower similarity with A.
This is useful because 2 pieces of texxt can contain different amounts of detail but still express the same general intest.

Cosine similarity does not "understand" truth.
2 false statements can be semantically similar.
2 harmful instructions can be semantically similar.
2 texts can be close in topic but disagree completely.

e.g. 
- Javascript is the best language.
- Javascript is the worst language.
may still have relatively similar embeddings because both discuss opinions aboubt Javascript.

Embeddings captures relationships.
They do not independently verify facts, intent, quality or safety.

# Token Embedding vs Text embeddings
Token embedding help a language model process a sequence internally.

Text embeddings are often produced specifically for tasks such as Search, Retrival, Clustering, Recommendation, Classification, Duplication detection.

The word "embedding" can refer to both, so always ask:
An embedding of what, and for which task?

Token embeddings help an LLM process individual tokens.
Text embeddings help application compare and retireve larger pieced of content.

# Static vs Contextual meaning
- I ate an Apple after lunch.
- Apple released a new device.

A simple static embedding system may assign one fixed vectorto the word "apple". That single vecotr must somehow represent both meanings.
That created a problem because words can have multiple meanings. This is called **ploysemy***.
The meaning depends on context.

Modern language models solve this more effectively using contextual representations. 
The representation of a token changes based on the surrounding words.

The same token can develop different contextual representations depending on the sentence around it.
Example :

"I ate an apple"
"Apple released a new iPhone"


# How modern LLMs handle context [Contextualization]
"Context modifies represensentation"

- I deposited money in bank.
- We sat on the bank of the river.

- He hit the ball with a bat.
- A bat flew out of the cave.

- Java is a programming language.
- Java is an island in Indonesia.
- I ordered Java at the cafe.

In a ***trandformer-based language model***, the token first recieves an initial token embediing.
Then the model processes it together with the surrounding tokens.

Through multiple layers, the representation beomes contextualized.

This means the representation of "bank" in:
- I deposited money in bank.
can become different from the represensentation of "bank" in:
- We sat on the bank of the river.

***The initial token may be the same. But after the model processes the complete sentence, its internal representation changes according to context.***



# Bias in Embeddings

*Human created data have a lot of flaws*

Human data contains:
- Cultural patterns
- Historical context
- stereotypes
- Social biases
- Representation gaps

As a result, embedding can also encode undesireable associatetions.
For example, some occupation may become more closely associated with one gender because of patterns in the training data.

***Embeddings represent pattern in data, that we may not want the system to reproduce.******
