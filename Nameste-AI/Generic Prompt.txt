# What does "learning" actually mean for a Machine
A Neural Network contains a huge collection of adjustable numbers the parameter

During training, we repeatedly modify those parameters so that the model becomes better at a particular objective.

For a neural network, learning means adjusting parameters so that future prediction become better.

GPT3 ----> 175 Billion parameters
GPT4 ----> 1.8 Trillion parameters [not official]
GPT5 ----> 100 Trillion parameters [not official]

Parameters are the learned numerical values that determine the model's behaviour.
Patterns and knowledge learned during training are encoded across these parameters.

# Parameters/weights
- Embedding
- Attention [Wq, Wk, Wv, Wo]
- Layer Norm [gama, beta]
- FFN [W1, W2, W3, ....]

# Does parameters store knowledge?
Not exactly.
Parameters store the **patterns** learned from data.
When the model predicts "Paris", it's not retrieving a stored string "Paris". Instead, the parameters adjust so that the output distribution favors "Paris" given the input.
Knowledge emerges from the **interactions** between these patterns.

# How is it related to training data?

## Forward pass
It's the process of taking input data and pushing it through the network to get an output.
Think of it as the "normal" usage of the model.

# Loss Function
It is a numerical way to measure how bad the prediction is.
A loss fn converts the quality of the prediction into a number.
correct prediction --> small loss
very wrong prediction --> large loss

The Sky is _______

for pred A loss == low and for pred B loss == high

There may be thousands, millions or billions of parameters.
Which parameters were responsible for the mistake?
And how should each one changes?

# Back Propagation
back propagation calculates how changing each parameter would affect the loss.

Backpropagation starts from the error at the output and works backward.
- How much did layer C contribute? How much did each weight contributes in layer C?
- What about layer B? what about weights inn layer B?
- and similarly for layer A?

It calculates the sensitivity of the loss to each parameter.

Mathematically, these sensitivites are called gradients.

# Gradients
A gradient tells us which direction a parameter should move to change the loss and how sensitive the loss is to that parameter.

Suppose a particular weight is: 0.40

The gradient tells us that increasing this weight would increasse the loss.
So perhaps we should move it slightly downward.
Another weight may need to move upward.

Backpropagation computes this information throughout the network.

Does Backpropagation fix the weights?
Backpropagation does not itself necessarily update theweights.
It calculates gradients.
Then an optimization algorithm uses those gradients to update the parameters.

# Gradient Descent  
Gradient descent is an iterative optimization algorithm used to minimize a function(like error or loss) by adjusting parameters in the opposite direction of the gradient.

Core Conepts:
- Loss function
- Gradient
- Learning Rate
ex. Imagine standing somewhere on a mountain in thick fog. Your goal is to reach the lowest point. The gradient tells you the slope direction. Take small steps. Repeat.

Main Types
- Batch Gradient Descent: Uses the entire dataset to compute the gradient for each step; stable but slow on huge datasets.
- Stochastic Gradient Descent(SGD): Uses a single data point per step; fast but noisy and fluctuates.
- Mini-Batch Gradient Descent: Splits data into small subset; strikes the best balance between speed and staability.

Challenges:
- Learning rate too small: Training takes forever.
- Learning rate too large: The algorithm overshoots the minimum and falls to converge.
- Local minima or saddle points: The system can get stuck where the slope is flat.

# Generalisation
