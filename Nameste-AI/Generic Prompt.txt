# Layer Normalization   
Layer normalization (layerNorm) is a techinque used to keep the numbers flowing through a neural network at a more stable scale.

[0.2,-0.34,0.5,0.6] -> [22,36,14,56]
As represntation repeatedly fo through attention, FNNs, residual additions, etc. their numerical  scales can become difficult to manage.

[0.18,-0.26,0.46,0.92]
Normalization helps keep the network's internal representations well behaved, which makes training deep networks more stable.


# Multi-Head Casual Self Attention

-Self Attention
it lets each token gather information from other tokens in the same sequence.

-Causal Self Attention(masked)
A token can look at itself and tokens before it, but never future tokens.

Causal is important because information is only allowed to flow in one direction. Past --> present

- Multi-Head
Run multiple self attention is parallel

Multi-head causal self attention allows every token to gather information from previous tokens using multiple attention heads, while preventing it from looking into the future.


# Residual/Skip Connection
Instead of completely replacing the old information with the output of a layer, we add the original input back to the layer's output.

Suppose a token represention entering attention is:
- x = [1,2,3]
Attention produces:
- Attention(x) = [0.2,-0.5,0.7]
Instead of only passing this forward:
- [0.2,-0.5,0.7]
we add the original input:
- [1,2,3] + [0.2,-0.5,0.7] = [1.2,1.5,3.7]

you can think of each layer as adding a useful update rather than rebuilding the entire represention from scratch.

*A Transformer layer doesn't throw away what it already knows. It learns an update and adds that update to the existing represnetiona.*
